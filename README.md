## 购买前需要注意的限制

### 这是自管理 VPS

搬瓦工提供基础设施和控制面板，但不会替你维护应用。服务器能否安全稳定运行，取决于你的配置和维护方式。

至少建议完成以下设置：

1. 使用 SSH 密钥登录，关闭或限制密码登录；
2. 修改默认 SSH 端口只能算辅助措施，不能代替密钥认证；
3. 配置防火墙，只开放必要端口；
4. 定期更新系统和应用；
5. 为数据库和网站文件设置自动备份；
6. 记录服务器资源使用情况；
7. 为域名、面板和数据库设置独立强密码；
8. 不要在公网暴露不必要的管理接口。

### 流量不是无限的

香港六个档位的月流量分别为 500GB、1TB、2TB、4TB、6TB 和 8TB。流量用完后如何处理，应以服务条款和账户页面显示为准，不要默认可以无限超额使用。

视频分发、大文件下载、镜像同步和高频 API 调用都可能快速消耗流量。静态网页、个人博客和低频后台服务的消耗则相对可控。
